# Security Policy

## Reporting a vulnerability

Please report security issues privately through
[GitHub security advisories](https://github.com/huntsman11177/cg/security/advisories/new)
rather than opening a public issue that contains exploit details.

Do not include secrets, credentials, or sensitive data in public issues.

## Scope

Security reports involving file traversal, malformed input handling, memory
safety, denial of service, or unsafe command execution are relevant to this
project.
